# Roadmap

## Near term

- Keep the CLI schema, documentation, and mock-target behavior deterministic.
- Improve portable CI and contributor onboarding.
- Expand authorized native-harness coverage with retained evidence.
- Establish reproducible campaign and release practices.

## Proposals

Open an issue before substantial work. Target and capability proposals must
state the authorization model, safety impact, test plan, and documentation
impact. Roadmap priority is based on user safety, reproducibility, maintenance
cost, and available reviewer capacity.
