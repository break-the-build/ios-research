# Community health

Maintainers review community health quarterly using privacy-preserving
aggregates: time to first issue response, pull-request review latency, aged
issues, availability of newcomer-labelled work, repeat contributors, and the
number of reproducibility reports that include the required record.

The goal is improvement, not surveillance. Do not collect researcher identities,
target details, private findings, or other sensitive content for these metrics.
The summary and any resulting actions are published in the project
announcements discussion.
